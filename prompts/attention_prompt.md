# 提示词 — 长上下文显存优化（HCA/MLA）

## 任务
为「{模型} 在 {上下文长度} 上下文下 KV 显存超预算」的场景给出分层缓存方案。

## 输出要求
1. 预算账本：列出 full attention / MLA / HCA 三种模式每层 KV 的公式与数值；
2. 分层策略：每 {full_ctx_every} 层只 1 层全上下文（MLA rank={mla_rank}），
   其余层 HCA（window={window}, global={global}）；
3. 诚实的代价：说明「预算外历史不可检索」对 {下游任务} 的影响与缓解办法；
4. 可复用要点：2-3 条能直接搬到生产的关键结论。

## 背景
长上下文是「容量换召回」的显式权衡，先定预算再谈命中率。
