# 示例

可直接运行，全部零依赖：

| 文件 | 说明 |
| --- | --- |
| `skill_curve.py` | 四项单调指标随 skill 的曲线 |
| `memory_ablation.py` | KV 显存压缩比随缓存预算的消融 |
| `echo_demo.py` | ECHO 多步预测逐步演示 |
| `http_api.py` | 用 urllib 调用零依赖 HTTP API |

```bash
python examples/skill_curve.py
python examples/memory_ablation.py
python examples/echo_demo.py
```
